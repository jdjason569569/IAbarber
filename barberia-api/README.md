# BarberIA API

NestJS backend for the BarberIA app (`../barberia-app`).

## Commands

```bash
npm install          # install dependencies
npm run start:dev    # development server with watch mode (http://localhost:3000)
npm run build        # compile to dist/
npm run start:prod   # run the compiled build
```

The port can be changed with the `PORT` environment variable. CORS is enabled so the Ionic app can call the API.
